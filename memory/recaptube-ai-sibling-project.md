**RecapTube AI** lives at `D:\Documenti\Development\RecapTubeAI`, created 2026-06-01 by cloning SkipTube AI's architecture. It takes a YouTube transcript and produces: (1) an AI **summary** + key points, (2) **translation** — summary written directly in the browser language (`navigator.language`, implicit translation), and (3) **auto chapters** with timestamps, generated ONLY when the video has no native creator chapters.

UI: an **in-page panel** injected into the YouTube sidebar (`#secondary-inner` → fallbacks), plus clickable chapter **markers on the progress bar**. Output language is auto (browser) with manual override in the popup.

Key design points carried over / changed from SkipTube:
- Reused verbatim: 3-layer transcript extraction (`transcript-service.js`, `transcript-interceptor.js`), provider abstraction (`providers/*`), logger, errors, validators, `Transcript` model.
- New: `src/shared/services/recap-service.js` (one AI call → summary+translation+chapters JSON), rewritten `background-main.js` (`generateRecap` action, cache key `recap_${videoId}_${lang}`), rewritten `content-main.js` (`RecapManager`), new popup.
- **Cross-extension safety**: interceptor uses `RT_INTERCEPTOR`/`RT_TRANSCRIPT` and flag `window.__rtInterceptorInstalled` (NOT SkipTube's `YSS_*`/`__yssInterceptorInstalled`) so both can run on the same page. Injected DOM uses `rt-` class prefix.
- Build is identical Rollup setup; `npm run build` → `dist/`. Models/config kept in sync with SkipTube (Claude haiku/sonnet, OpenAI gpt-5.5/5.4-mini/5.4-nano).
