# Chrome Web Store Promo Video

Code-driven promotional video for the global Chrome Web Store listing of **SkipTube AI**.

## Output

- Video: `../promotional-video/skiptube-ai-promo.mp4`
- Thumbnail: `../promotional-video/skiptube-ai-promo-thumbnail.png`
- Format: 1920 x 1080, 30s, H.264 MP4
- Usage: upload the MP4 to YouTube, then paste the resulting URL into the Chrome Web Store global promotional video field.

## Commands

```bash
npm install
npm run render
npm run thumbnail
```

The first Remotion render may download a Chromium Headless Shell.
