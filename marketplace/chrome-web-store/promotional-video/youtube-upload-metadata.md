## Description

SkipTube AI is an AI-powered Chrome extension that helps you skip YouTube sponsorships, intros, outros, donation reads, and self-promotional segments automatically.

The extension analyzes available video transcripts with your selected AI provider, marks detected segments on the YouTube timeline, and skips them based on your preferences. You can choose which categories to skip, adjust confidence settings, exclude channels, and reuse locally cached results for previously analyzed videos.

Install SkipTube AI from the Chrome Web Store:
https://chromewebstore.google.com/detail/skiptube-ai/jinbffngeajdaalfakephodepnmpocbi

GitHub:
https://github.com/ChromuSx/SkipTubeAI

Privacy Policy:
https://github.com/ChromuSx/SkipTubeAI/blob/main/PRIVACY.md

Key features:
- AI transcript analysis for sponsor and promo detection
- Automatic skipping during YouTube playback
- Timeline markers for detected segments
- Category-level controls for sponsorships, intros, outros, donations, and self-promotion
- Channel exclusions
- Local settings, statistics, and 30-day analysis cache
- Bring your own Anthropic Claude or OpenAI API key

SkipTube AI is an independent open source project. It is not affiliated with YouTube, Google, Anthropic, or OpenAI.
